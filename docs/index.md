# Shorts Autopilot

Shorts Autopilot is an open-source tool that produces short vertical videos (YouTube Shorts) from code: a language
model writes the script, a text-to-speech engine records it, and the video is rendered with Remotion. A scheduled
GitHub Actions workflow runs it every day and uploads the finished videos to the YouTube channels owned by the
person who operates the tool.

- [Privacy policy](privacy.md)
- [Terms of service](terms.md)
- Source code: this repository

The tool is operated by a single person for their own YouTube channels. It is not a service for other users and it
does not collect data from viewers or from anyone else.
